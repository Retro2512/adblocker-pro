# Security

Adblocker Pro is a local preference tool, not a parental control or administrative security boundary. A user or a hostile page can bypass it. Do not depend on it to enforce a device policy.

Report vulnerabilities privately to the maintainer contact supplied by the repository publisher. Include a minimal fixture, browser or Windows version, and steps to reproduce. Do not attach listening history, credentials or personal browser profiles.

Security relevant areas include settings message authorization, imported JSON validation, cross frame status, mute ownership and preservation of user playback intent. Runtime remote code and remote metadata collection are outside this project's design.
